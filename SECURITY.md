# Security policy

This MVP is a single-user loopback application. Do not expose it directly to the Internet.
Never place credentials in prompts, source files, fixtures, logs, or issue reports.
Generated real-project code must execute through the Docker adapter; no host fallback is supported.

Report suspected vulnerabilities privately to the repository maintainer via the hosting provider's
private security reporting feature when available. A maintainer contact is not yet configured;
do not publish exploit details or secrets in public issues. See docs/sandbox.md for current boundaries.
