# Contributing

Read PRODUCT_DEVELOPMENT_SPEC.md and docs/architecture.md before changing shared interfaces.
Use a branch/worktree, keep changes focused, and include failure-path tests for behavior changes.
Run the README verification commands. Contract changes must update docs/contracts.md and affected tests.
Do not include credentials, generated local workspaces, or private model context in commits.
Report actual commands and results in pull requests. Passing model review never replaces executable tests.
