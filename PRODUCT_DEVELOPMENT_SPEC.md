# Micro-Multi product guide

Micro-Multi is a local desktop workspace for model configuration, projects, conversations, multi-agent collaboration, and extensions compatible with the deepseek-harness (dsh) plugin ecosystem.

See the [README](README.md), [architecture](docs/architecture.md), [collaboration guide](docs/AUTONOMOUS_COLLABORATION.md), and [dsh plugin guide](docs/NATIVE_CORDIS.md) for product behavior and development interfaces.
