# 查看对话记录

打开已有对话，可以阅读回复、工具调用、操作审批和成员报告。这些记录帮助你在继续任务前了解已经发生的操作。

涉及文件修改时，对照当前内容、Git 差异和智能体说明；涉及命令时，查看参数、退出状态及输出；涉及团队时，将成员报告与对应文件和验证结果一起检查。

任务中断后，部分操作可能已经完成。要求重做前，先检查已有文件、运行中的进程或远端变化。继续时说明缺少的部分，例如：“测试已通过，但接口文档还没写，请接着补上。”

对话记录属于本地应用数据，可能包含项目内容和工具输出，分享前应清理私人信息。参见[保存与恢复](DURABLE_TURNS_AND_MODEL_RECOVERY.zh-CN.md)和[数据存储](deployment.zh-CN.md)。
