# 自主协作

在对话输入区选择多 Agent 协作，并说明目标、约束和验收方式。主 Agent 拆分任务，为成员分配职责和模型，收集报告并检查结果。独立工作可以并行推进，共享修改需要协调文件范围。

团队视图展示成员状态、任务和返回内容。工具记录展示文件操作、命令、扩展调用及审批结果。可以在运行中补充说明，或暂停、停止当前执行。

模型在“模型”页面配置。不同成员可以使用不同的兼容模型接口。dsh 插件工具、Skills 和 MCP 工具通过统一工具目录供主 Agent 和成员使用，操作遵循当前权限设置。

完成后检查文件差异、验证结果和成员报告。后续对话可以继续调整目标，并保留工作区上下文。
