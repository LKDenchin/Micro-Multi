# 当前源码变化 — 2026-10-05

本次更新基于已发布的 0.1.0 桌面版本，包版本仍为 0.1.0。更新源码与文档，不发布新 Release，也不替换已有安装包。

## 插件

- 宿主、服务提供者和浏览器客户端使用原生 Cordis Loader 条目加载，保留条目选项、隔离、校验、生命周期与回滚。
- 根据 dsh 基础组合和依赖元数据递归发现真实服务，将定时器、会话查询、工作区及存储纳入生产依赖。
- 自动将已声明的缺失库及构建工具安装到受管理缓存；支持隐藏包元数据、同步/异步工厂与分块，框架 ABI 与锁定宿主 SDK 保持一致。
- 原始旧版 SettingsProvider 与原生 Config 表单共存；更新经过校验、完整重启及原子保存，失败或重启后恢复正确配置。
- 设置与 body portal 限制在详情页，明确的对话/shell 贡献显示到相应区域；使用原生语言运行时及嵌套槽位所有权。
- 禁用浏览器 Node 内部探测，JS/CSS 和宿主缓存版本由当前源码及依赖产生。
- 使用经完整性验证的发布源码快照保护框架，保留许可证；原生 HTTP 支持二进制与流，长期订阅改用 WebSocket。

## 对话与团队

- 审核方案实时展示并持久化，每版方案单独确认，保留成员明确指定的模型。
- 同一成员/任务重复调度去重，新任务与失败重试仍正常执行，取消后释放预留。
- 明确拒绝的模型可选参数进行有限协商；保留具体失败原因、结束状态、推理及结构化工具输出。
- 合并流、存储及渲染更新，保留 SQLite 持久性，复用 MCP 连接并清理取消调用。
- 稳定启动观察器与窄输入栏布局，防止全局控件逻辑修改 React 插件控件。

## 文档与验证

中英文正文、导航、搜索及对应页链接独立。Pages 在 main 推送后根据仓库 Markdown 重建。历史验证记录保留日期和范围，不代表当前安装包重新构建。程序回归覆盖服务、设置、回滚、无 Node 全局的浏览器环境、依赖安装、portal 及启动。本次验证未使用模拟点击。
