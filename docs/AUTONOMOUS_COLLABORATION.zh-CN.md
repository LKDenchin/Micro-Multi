# 经审核的团队协作

在输入区选择多 Agent 协作，说明目标、约束和验收条件。主 Agent 先分析需求、读取资料并编写需求、设计及任务文档，再提交完整团队方案。准备阶段仅允许分析与方案文档操作，不启动成员。

## 审核与执行

协作卡片展示待审核方案。“调整团队”可编辑职责、提示词、文件负责范围及模型；“确认执行”只启动当前版本。新任务或反馈生成新版方案，不沿用旧批准。批准仅消费一次，过期卡片不能启动任务。审核记录位于 `.masp/team-plans/`，聊天历史保留卡片。

成员默认跟随主模型。团队编辑器中的明确模型选择保留并用于实际执行；模型生成的成员创建或调度不能静默替换这些选择。保存团队同步主模型与输入区选择器。

## 跟踪、中断与恢复

团队视图展示状态、任务和报告；工具记录展示文件、命令、扩展调用与审批。运行中可补充指导，也可暂停或停止。主 Agent 可调用 `remove_subagent` 取消失败成员；等待取消完成并释放文件预留后再尝试其他方案。

同一轮、同一成员、同一任务重复调度共享已有执行或完成报告。新任务正常执行，失败任务可以重试。新增验收条件仍需主 Agent 核查，复用报告不代表运行了新的验证。

在“模型”配置接口，在“自定义”管理插件、Skills 和 MCP。输入区 + 菜单列出已启用能力；原生插件工具同时供主 Agent 与成员使用。交付前检查差异、验证和报告，并可在原对话中继续。参见[模型与恢复](DURABLE_TURNS_AND_MODEL_RECOVERY.zh-CN.md)和[原生插件](NATIVE_CORDIS.zh-CN.md)。
