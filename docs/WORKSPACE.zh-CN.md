# 项目与对话

项目将对话关联到一个本地目录。智能体在该目录中操作，你可以在工作区中阅读文件和检查改动。只需要提问、不涉及本地文件时，也可以创建不关联项目的对话。

## 打开项目

添加本地项目时，填写名称并选择目录。勾选“直接关联此目录”后，文件修改会作用于原目录；没有 Git 的目录会自动初始化仓库。确认前检查路径，尤其是导入已有项目时。

新建对话时选择该项目。文件树展示目录内容，可以打开文件阅读，并通过“改动”或“审查”查看 Git 差异。项目自己的构建工具和依赖仍需安装，以便在目录中运行命令。

## 开始和继续对话

在输入区选择模型、模式和权限，再描述任务。尽量说明涉及的文件或行为、需要遵守的限制，以及检查方法。例如，哪些响应字段必须保留，或应该运行哪些测试。

通过附件入口添加相关文件，+ 菜单列出已启用工具及其他能力。回复、工具调用和团队报告随对话保留；下次从列表打开后，可以直接补充要求，不必重新开始。

## 检查工作结果

回复说明智能体做了什么，文件和工具记录展示实际结果。代码任务应查看差异，验证任务应检查命令输出。测试失败可能来自本次改动、环境或已有问题，应根据记录中的输出判断下一步。

右侧工作区集中展示文件、差异、审查、预览和终端活动。团队模式还可查看每个成员的任务与状态。正在执行的对话可以暂停或停止，已经完成的操作会保留在磁盘上。中断后重做任务前，参见[历史记录](replay.zh-CN.md)和[恢复](DURABLE_TURNS_AND_MODEL_RECOVERY.zh-CN.md)。
