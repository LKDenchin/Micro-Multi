# 添加指令和工具

扩展可以为智能体补充任务指令，或接入内置工作区之外的工具。在“自定义”中管理插件、Skills 和 MCP 服务，按需要添加的内容选择类型。

## Skills：复用工作指令

Skill 是一个说明怎样完成任务的 `SKILL.md` 文件，可用于项目规范、审查清单或经常重复的流程。项目 Skills 放在 `.agents/skills/`，用户 Skill 也可通过“自定义”添加。指令应说明何时适用，以及完成任务需要满足哪些要求。

## MCP：接入服务的工具

MCP 连接暴露本地或远程服务的工具。配置服务地址或启动命令，以及所需凭据后，检查连接是否可用。本地服务需要安装相应运行时和依赖，远程服务需要可访问的接口。为任务启用实际需要的工具即可。

## 插件：增加应用能力

插件页面包含目录和已安装包。打开条目阅读介绍，安装后在详情页配置参数。dsh 插件可以增加工具、模型提供者或对话界面控件；本地命令插件提供由命令实现的工具。

有些插件需要外部程序、账号或独立 API 密钥，应先完成这些配置，再让智能体调用。禁用后不再提供活动功能，移除则卸载包。[dsh 指南](NATIVE_CORDIS.zh-CN.md)介绍来源类型和插件开发。

## 在对话中使用扩展

输入区的 + 菜单列出已启用能力。说明何时应使用某个工具或 Skill，再从对话中检查实际调用。原生插件提供的工具同时供主智能体和团队成员使用。

启用前检查来源及访问要求。本地程序和原生插件以你的系统账号运行，外部服务也可能收到任务数据。应用的操作控制见[权限说明](sandbox.zh-CN.md)。
