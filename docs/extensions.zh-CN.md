# 扩展与工具

Skills 在 `SKILL.md` 中提供可复用指令。项目 Skills 放在 `.agents/skills/`，用户 Skills 可通过工作区添加。配置 MCP 连接后，服务暴露相应工具；本地命令插件连接命令型工具。

Micro-Multi 同时支持 deepseek-harness（dsh）Cordis Host 生态，覆盖宿主工具、原生服务及客户端贡献。[插件指南](NATIVE_CORDIS.zh-CN.md)介绍包入口、依赖构建、设置、服务注入、生命周期和权限。

在“自定义”管理扩展；部分入口位于“设置”。加载前检查代码、来源和访问要求，通过工作区权限控制操作。需要源码构建的插件沿用审核流程；第三方 CLI、账号和凭据按插件说明配置。输入区 + 菜单列出真实启用能力。
