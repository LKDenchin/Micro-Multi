# 权限

开始任务前，在对话输入区选择操作权限。它决定应用工具中哪些操作自动执行，哪些需要你确认。

| 选项 | 行为 |
| --- | --- |
| 请求批准 | 读取自动执行，修改文件和运行命令需要确认。 |
| 帮我批准 | 读取和修改文件自动执行，运行命令需要确认。 |
| 完全访问 | 允许文件访问、命令及已启用的外部能力，包括 MCP 工具。 |

出现审批时，阅读具体操作并判断是否符合任务。团队方案确认启动约定的协作，操作审批则控制某次具体动作，两者作用不同。

Electron 渲染进程使用上下文隔离和 Chromium 沙箱。本地命令和原生插件仍以你的系统用户权限在主机执行，操作权限不会将任意本地程序变成沙箱进程。

Docker 验证需要单独安装 Docker。隔离执行拒绝回退到主机，但不会隔离所有对话工具和扩展。凭据不要放入项目文件；发送给模型或扩展的数据也应先检查。信任边界及报告方式见[安全政策](../SECURITY.zh-CN.md)。
