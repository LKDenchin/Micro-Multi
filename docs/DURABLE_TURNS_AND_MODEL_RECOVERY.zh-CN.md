# 对话、流式输出与模型恢复

项目、对话、工具事件和流式回复保存在本地数据目录。重新打开已有对话可继续工作。长会话通过上下文压缩保留任务信息及循环检测状态。

流事件合并时保留语义边界和最终状态。批量持久化、增量回放、Markdown 调度及目录刷新合并减少重复工作。SQLite 保留 WAL 和完整同步策略。MCP 发现使用缓存，连接复用，取消时清理活动调用。

兼容模型请求支持 SSE 或 JSON、文本内容块、推理字段及结构化工具参数。供应商在生成前通过 HTTP 400/422 明确拒绝可选参数时，有限次协商移除该参数，或在供应商指定替代名称时重命名 token 上限。消息、工具、模型选择和认证仍为必要字段。协商结果按接口与模型缓存。

停止后保留已记录内容。网络错误和截断保留实际原因，未完成输出不标记成功。检查接口、网络与凭据后在已有对话中继续；重复有副作用的操作前检查文件和工具记录。

桌面监测后端退出和渲染状态，记录诊断并恢复工作界面。日志位于应用数据目录，分享前移除敏感内容。存储路径见[部署](deployment.zh-CN.md)，此次源码变化见[当前变化](CURRENT_CHANGES.zh-CN.md)。
